# AI Content Detector v1

This tool analyzes writing patterns to estimate the likelihood that text
contains AI-generated characteristics.

## What it does
- Detects AI writing patterns using deterministic heuristics
- Returns a probability score and risk level
- Explains results in plain language

## What it does NOT do
- Identify specific AI models
- Claim certainty
- Rewrite or edit content
- Detect plagiarism

## Input
- Plain text only
- Minimum 300 characters
- Maximum depends on API limits

## Output
- AI probability (0–100)
- Classification: Likely Human, Mixed, Likely AI
- Confidence level
- Risk level (SEO/publishing)
- Explanation of detected patterns

## Disclaimer
AI detection is probabilistic, not definitive.
Results should be interpreted as risk signals, not proof.
